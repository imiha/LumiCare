# Architectural Decision Records

This directory captures key architecture decisions made during the project.

## What is an ADR?

A short, structured document that records **one decision**: why it was made, what alternatives were considered, and what consequences follow. Write one whenever the team makes a choice that would surprise a future reader or that is hard to reverse.

## Template

Copy `ADR-000-template.md` when creating a new record. File names follow the pattern `ADR-NNN-short-title.md`.

## Status values

| Status | Meaning |
|---|---|
| `Proposed` | Under discussion — not yet implemented |
| `Accepted` | Decision made and implemented |
| `Superseded by ADR-NNN` | Replaced by a later decision |
| `Deprecated` | No longer applies |
